# BlockHabit

极简黑白风格的桌面习惯打卡应用 —— 每次打卡掉落一块 2.5D 等距积木，积木按蓝图逐块拼成城堡、工厂。

![BlockHabit](src/assets/logo.svg)

## 特性

- **习惯打卡**：每天 / 每周 N 次两种频率，同日幂等，周频上限防刷块；习惯支持选填时段 / 目标时长 / 备注（必填与选填字段用小方块图标区分），今日页按时段分组
- **积木奖励**：每次有效打卡掉落一块积木；连击每满 7 天，下一块为点缀色 bonus 积木；撤销打卡有确认保护，missed 天可用修复积木补卡
- **建造视图**：Canvas 等距渲染**圆润乐高积木**（圆角面 + 顶面凸点），地面虚线标出地基范围、建筑脚印接触阴影，滚轮缩放 / 拖拽平移；落块动画：慢落 → 着地压扁 → 回弹；拼完触发落成仪式
- **模型图鉴**：23 个等距积木模型（基础 12 座 + 免费扩展包 v2 6 座 + v3 5 座，绿意盆栽 → 水塔），带实时渲染缩略图，按顺序解锁，拼完可开下一座；锁定态用剪影呈现，不剧透细节；每座都有独立材质配色（石/木/陶土/黄铜/铜绿等，见 `D-20261111-067` / `D-20261111-070`）
- **自由装饰模式**：全部蓝图落成后展台解锁「装饰模式」——可对已陈列模型做 90° 旋转、换一组微生态植被；旋转与植被仅本次会话有效（不写存档、重开复原），不新增沙盒经济（D-20261111-068）
- **到点提醒**：习惯可设置提醒时段，应用运行中（含托盘/窗口隐藏）弹系统通知 + 应用内提示
- **WebDAV 同步**：多设备合并（打卡墓碑化防复活），支持自动同步与手动立即同步；桌面端走 Tauri 原生 HTTP（不受 WebView CORS 限制）。设置页提供服务商预设（Nextcloud / 坚果云 / 群晖 / 通用）与**分步连接自检**（地址 → 连接 → 认证 → 读写 → 清理），失败时指出具体阶段与处理建议，不触发同步合并（D-20261110-061）；浏览器预览仍受跨域限制，会明确提示在桌面端重试
- **统计**：当前/最长连击、总次数、近 13 周日历热图（灰阶点亮，全完成日满亮）、打卡随笔手账、月度画报
- **本地优先**：Tauri 环境存 `appDataDir/blockhabit.json`，浏览器回退 localStorage；支持导出/导入 JSON
- **备份与恢复**：覆盖导入前自动留档（保留 5 份），手动快照单独保留 5 份；设置页可看到备份列表、一键恢复、直接打开数据目录
- **首启引导**：空态给出「建第一个习惯 → 打一次卡 → 看它长起来」三步说明，第一块积木落下时单独解释它去了哪里
- **今日简报**：打开即见问候、今日完成进度、当前蓝图离落成还差几块，「开始第一个」直接定位到第一件未完成习惯（D-20261110-052）
- **模板起步**：首启空态提供喝水 / 阅读 / 走动 / 早睡 / 记账 5 个一键模板，点一下即创建真实习惯（D-20261110-053）
- **页面提示**：建造 / 展台 / 统计首次进入各给一条可关闭的用法提示，设置页「实验室」可重看；tab 补 1–4 快捷键提示（D-20261110-054）
- **晚间收尾提醒**：首次打卡后一次性询问是否每天 21:00 提醒；默认关、每天最多一次、只陈述还剩几件（D-20261110-055）
- **桌面摆件三档**：口袋 220×150 / 标准 280×400 / 展台 420×560；置顶默认关，位置按当前显示器工作区钳制；口袋只看进度+一键打卡，展台显示今日清单（D-20261110-059）
- **落成年鉴**：统计页按年生成竖版年鉴（总览 / 12 个月热图 / 建筑年表 / 时间形状 / 当年一句），可保存图片、复制图片或导出 Markdown；完全本地生成，零新字段（D-20261110-060）
- **建筑档案**：图鉴里每座已落成建筑可打开档案卡——落成日、耗时、投入最多习惯、关键块时间线（可看当天随笔与心境）、铭言编辑、拍立得与档案卡 PNG（D-20261110-065）
- **完整档案包**：设置 → 数据安全一键导出 README + manifest + 数据 JSON + 校验清单 + 已落成建筑透明图；桌面写入本地 exports 文件夹，浏览器下载单 ZIP，不含 WebDAV 凭据（D-20261110-062）
- **专注陪伴**：专注会话跨重启保留（设备本地），摆件显示倒计时/环形进度，到点确认才落块，可延后 5 分钟（最多 2 次）或放弃；不监控、不阻断、不自动完成（D-20261110-064）
- **版本与更新**：设置 → 内容路线提供手动「检查更新」入口（无启动自动检查、无静默下载）；发布链路（签名密钥/发布端点）未配置时按钮诚实禁用，默认构建零外部网络请求（D-20261111-069）
- **视觉**：全面圆润化（胶囊 tab / 圆角卡片 / 软阴影弹窗），纸白 / 墨黑 / 燕麦陶土 / 北欧雾灰四主题，点缀色跟随主题
- **字体**：Rubik（几何拉丁与数字）+ MiSans（中文正文）+ 阿里妈妈数黑体（标题），离线打包

## 已知限制

- **WebDAV**：**桌面端**已走 Tauri 原生 HTTP 通道（`src/platform/http.ts`），不再受 WebView 的 CORS 限制；**浏览器预览**（`npm run dev`）仍走标准 `fetch`，Nextcloud 等默认不返回跨域头时会失败，提示会明确指向「跨域被拦」而不是伪装成网络错误。
- **没有自动更新**：当前不做自动检查/静默下载。设置页「内容路线」提供手动「检查更新」入口，但发布链路（签名密钥、发布端点）尚未启用时按钮诚实禁用——请以发布说明为准手动下载覆盖安装。
- **内容上限**：23 座蓝图共 2485 块（基础 12 座 1385 块 + 扩展包 v2 6 座 600 块 + v3 5 座 500 块；配色阶段为树屋 +4、石桥 +2）。全部建成后不再掉落新积木，但**不会静默**：建造页常驻完成态说明，打卡时会明确告知「已记录、但不再产生新积木」。内容版本门（`contentVersion=3`）保证旧客户端不会静默丢新建筑数据；扩展包随安装包内置、免费，不做运行时下载。

## 平台范围

- **桌面端（Windows）是唯一正式目标**：托盘、单实例、关窗存档握手、原生通知、备份目录都只在这条路径上验证。
- **移动端为「实验」状态**（2026-11-10 决议，见 `design/records/D-20261110-050-platform-scope.md`）：代码里保留了响应式布局与触摸手势，但**没有构建目标、不投入继续开发**。若要正式支持，需要单独一轮：移动构建流水线、安全区适配、触摸目标尺寸复查。
- **提醒依赖进程存活**：应用完全退出后不会提醒；开启「开机自启」可缓解。

## 技术栈

Tauri 2 · React 19 · TypeScript · Vite · zustand · Canvas 2D · vitest

```
src/
  logic/      纯逻辑：打卡规则 / 连击 / 蓝图（单测覆盖）
  render/     等距投影 + 乐高积木绘制 + 建造场景（落块回弹动画）
  storage/    StorageAdapter 抽象（localStorage / Tauri fs）
  store/      zustand 全局状态 + 防抖持久化
  pages/      今日 / 建造 / 展台 / 统计
  components/ 图标库（积木风 SVG）/ 热图 / 表单
```

## 开发

```bash
npm install
npm run tauri dev    # 桌面窗口（首次 Rust 编译约 3-10 分钟）
npm run dev          # 仅浏览器预览 http://localhost:1420
npm test             # vitest
npm run design:check  # 设计台账一致性 + 未审批删除检测
npm run check:versions # 三处构建版本号一致性（CI 门禁）
npm run tauri build  # 出安装包 src-tauri/target/release/bundle/
```

> Git Bash 下跑 cargo 需把 MSVC `link.exe` 目录放到 PATH 最前（避免命中 coreutils link）：
> `export PATH="/c/Program Files/Microsoft Visual Studio/2022/Community/VC/Tools/MSVC/<ver>/bin/Hostx64/x64:$HOME/.cargo/bin:$PATH"`
