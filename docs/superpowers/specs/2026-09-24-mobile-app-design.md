# BlockHabit 移动端 (iOS & Android) 设计规格说明书

日期：2026-09-24  
状态：已批准（待实施）  

---

## 1. 产品概述与目标

**BlockHabit 移动端**是基于现有 Tauri 2 + React 19 + TypeScript + HTML5 Canvas 架构打造的跨平台原生体验移动应用，同时支持 **iOS** 与 **Android**。

### 1.1 核心设计目标
1. **轻量极速，极致美感**：延续桌面端“包豪斯几何极简 + 实体积木切角”的品牌设计语言，无繁杂装饰，以 1px 细线、利落倒角与主题色块构建高品质移动视效。
2. **交互体验不妥协**：将桌面端鼠标操作完美升华至移动端多点触控（捏合缩放、单指平移、双指微扭旋转、射线拾取）与清脆触觉振动（Haptics），维持“打卡即落块、积木成建筑”的实体拼搭仪式感。
3. **本地优先与跨端无缝协同**：保持 Local-First 架构，集成标准 WebDAV 双向静默同步协议与 CRDT 启发式冲突消解，实现手机端与桌面端数据的无缝一致。
4. **单代码库高复用性**：复用 100% 现有领域模型、蓝图生成算法、状态机与 2.5D 等距画布数学引擎，通过平台抽象层（`usePlatform`）实现多端自适应。

## 2. 关键架构与技术决策

| 决策维度 | 选定方案 | 决策依据与优势 |
|---|---|---|
| **技术栈基石** | Tauri v2 Mobile (`tauri ios` / `tauri android`) | 零迁移成本，100% 复用现有 React 19 + Zustand + 2.5D Canvas 核心，兼具轻量内存占用与原生系统能力 |
| **代码组织** | 单代码库响应式与平台感知架构 (`usePlatform`) | 保证桌面端与移动端后续功能迭代零时差同步，避免双代码库的维护地狱与逻辑漂移 |
| **画布渲染** | 原生 HTML5 Canvas 2D + 移动端手势调度器 | 纯数学等距投影（Isometric Projection），无重型 3D 引擎负担，超低功耗，完美适配 120Hz 移动高刷屏 |
| **数据持久化** | 本地沙盒 JSON + 异步 WebDAV 双向同步 | 保障离线可用与数据隐私；支持坚果云/Nextcloud/NAS/InfiniCLOUD，支持 CRDT 并集去重 |
| **触感反馈** | 原生 Haptic Feedback 集成 (Light/Medium/Heavy/Success) | 赋予落块、卡扣、步进物理机械键盘般的段落触觉反馈 |

## 3. 视觉美学体系与多端自适应规范

### 3.1 字体与排版体系
移动端完全复用桌面端严苛的几何字体规范：
* **数字与英文**：全局采用 `Rubik`。具备 3D 魔方与立方体积木定制的微倒角几何体，移动端大字号打卡倒计时与连击计数极具玩具质感。
* **中文与排版**：采用 `AlimamaShuHeiTi`（阿里妈妈数黑体）结合平台无衬线体回退（iOS `-apple-system`, Android `MiSans/Roboto`），保持硬朗切角与方块结构。
* **视觉层级**：
  * 大数字强调（打卡天数/倒计时）：`Rubik`, 32px ~ 48px, line-height: 1.1
  * 页面与分组标题：17px, font-weight: 700, 紧致字偶间距（`-0.02em`）
  * 习惯正文与状态文字：15px, font-weight: 500
  * 次要辅助与时间戳：12px ~ 13px, color: `var(--ink-2)`

### 3.2 色彩体系与四套主题适配
移动端无缝支持已有的 4 套调色板，并严格遵循色彩纪律：
* `Light`（纯白积木）：背景 `#fafafa`，表面 `#ffffff`，线条 `#e8e8e8`，点缀色 `#f5b301`（琥珀金）
* `Dark`（黑曜石极夜）：背景 `#0a0a0a`，表面 `#171717`，线条 `#2b2b2b`，点缀色 `#f5b301`
* `Oat`（燕麦暖木）：背景 `#f7f4ee`，表面 `#ffffff`，线条 `#e7e2d7`，点缀色 `#c25e3e`（暖陶橙）
* `Fog`（冷雾灰蓝）：背景 `#f1f4f8`，表面 `#ffffff`，线条 `#cbd5e1`，点缀色 `#0284c7`（深海蓝）

**点缀色纪律**：在移动端界面中，除已完成勾选、新落积木高亮以及连击奖励外，所有卡片与界面元素均保持克制的黑白灰层次，营造静谧专注的高级感。

### 3.3 视口与安全区（Safe Area Insets）
* **顶部状态栏（Status Bar）**：
  * 移除桌面端 TitleBar 与窗口控制按钮。
  * 注入 `padding-top: max(16px, env(safe-area-inset-top))`。
  * 页面顶部常驻紧凑型 Header（高度 48px）：
    * 左侧：BlockHabit 几何立体 Logo 徽章 + 当前 Tab 标题。
    * 右侧：全局设置入口（齿轮图标，触摸热区 44x44px）与 WebDAV 同步状态小指示灯（微绿点/微闪烁）。
  * 自动跟随主题设置系统状态栏颜色（iOS `UIStatusBarStyle`, Android `StatusBarColor`）。
* **底部安全区（Bottom Safe Area）**：
  * 注入 `padding-bottom: max(12px, env(safe-area-inset-bottom))`，预留手势操作条（Home Indicator）间距。

### 3.4 底部导航栏（Bottom TabBar）
* **定位与材质**：
  * 屏幕底部固定，高度 `56px` + 底部安全区。
  * 材质采用高质感毛玻璃微透（`backdrop-filter: blur(20px)`，半透明背景），上沿一条 1px 超细实线（`var(--line)`）。
* **四大 Tab 导航**：
  1. **今日 (Today)**：日历方块微标，未完成习惯时带有 4px 琥珀色提示点。
  2. **建造 (Build)**：2.5D 等距微缩积木图标，外围环绕极细微圆环展示当前蓝图总进度百分比。
  3. **展台 (Showcase)**：等距沙盘微标。
  4. **统计 (Stats)**：阶梯热力微标。
* **动效与触感**：
  * Tab 切换时触发清脆轻度振动（Light Haptic）。
  * 选中态带有平滑的胶囊底块平移动画（180ms ease-out），杜绝拖沓。

## 4. 核心页面移动端交互规格

### 4.1 今日页 (Today) — 极速轻量打卡流

```

+---------------------------------------+
| [蓝图进度胶囊: 风车磨坊 12/28 块 >]    |

+---------------------------------------+
| [晨间]                                 |
| +-----------------------------------+ |
| | [■] 晨间饮水 500ml      [+] 250ml | |  <- 步进卡片
| +-----------------------------------+ |
| | [■] 早晨冥想            [▶ 15:00] | |  <- 计时卡片
| +-----------------------------------+ |
| [任意时段]                             |
| +-----------------------------------+ |
| | [■] 阅读 30 分钟          [ 勾选 ]| |  <- 瞬时卡片
| +-----------------------------------+ |
|                                       |

+---------------------------------------+
```

1. **蓝图进度紧凑胶囊**：
   - 居于顶部，展示当前蓝图名称与完成度（如 `风车磨坊 12/28 块`）及微型进度条。
   - 点击整条胶囊，带有触感反馈并无缝平滑切至【建造】Tab。
2. **分类与时段筛选**：
   - 支持横向惯性滚动（`scroll-snap`），左右留白防遮挡。
   - 智能时段折叠：根据系统当前时间自动高亮当前时段分组（如晚 20:00 自动折叠已过去的晨间已完成项，聚焦夜间待办）。
3. **习惯卡片（HabitRow Mobile）**：
   - **瞬时打卡**：大面积触控热区，按下时卡片产生 `scale(0.98)` 微缩放，松手打卡成功，触发 Medium Haptic 振动。
   - **专注计时习惯（Focus）**：卡片右侧集成环形倒计时进度按钮，点击即在卡片内开始计时；长按可进入全屏专注沉浸模式（屏幕常亮、呼吸呼吸灯、翻转手机静音）。
   - **量化步进习惯（Counter）**：左右分别提供 `-` 与 `+` 按钮，最小触控尺寸 44×44px，长按支持连续加速步进，每步伴随清脆微振。
   - **手势快捷操作**：
     - 卡片向左滑动：滑出轻量红色“归档/删除”与灰色“编辑”快捷动作。
     - 卡片长按 350ms：呼出“记录微心情（MicroMood）与随笔（Echo Note）”底部抽屉。
4. **轻量化落块通知（Drop Notification）**：
   - 每次打卡成功后，不再强制弹出全屏打断式弹窗，改为**顶部灵动通知浮条**（“落下一块基础积木！”并伴随清脆机械音与震动）。
   - 用户连续打卡完毕后，切换到【建造】页即可观看连续落块果冻回弹。

### 4.2 建造页 (Build) — 2.5D 等距画布全屏触控

1. **沉浸式全屏画布**：
   - 移除所有复杂侧边框，Canvas 占据全屏核心视口。
   - 顶部悬浮毛玻璃胶囊：显示蓝图名称、落块数、落成百分比，点击可打开“蓝图图鉴（Gallery）”。
2. **触控手势引擎（Touch Gesture Engine）**：
   - **单指平移（1-Finger Pan）**：按住画布空白处任意滑动，平滑拖动视口，松手带自然摩擦力惯性滑动。
   - **双指捏合（2-Finger Pinch Zoom）**：以双指中心点为缩放原点，平滑无级缩放（0.5x ~ 3.0x）。
   - **快速旋转**：
     - 画布右下角浮动两个半透明圆角切角按钮：`[↺ 90°]` 与 `[↻ 90°]`，单手拇指即可一键旋转视口。
     - 同时支持**双指旋转手势（Two-Finger Twist）**，转动超过 45° 自动平滑吸附到最近的 90° 象限（0°/90°/180°/270°）。
   - **双击重置（Double Tap）**：双击画布空白处，视口平滑复位至居中最佳观赏视角。
3. **轻触积木射线拾取（Tap to Inspect）**：
   - 复用 `iso.ts` 的 `isPointInsideCube` 射线多边形判定。
   - 手机单指轻触建筑中任意一块积木：
     - 积木顶面与边缘高亮闪烁一次。
     - 触发 Light Haptic。
     - 屏幕底部滑出微型信息卡片：“第 14 块积木 · 来自习惯【早睡早起】 · 2026-09-18 落块”。
4. **落成仪式（Celebration Ceremony）**：
   - 蓝图拼满最后一刻，触发全屏灰白金积木粒子飘落（Confetti）。
   - 手机连续三次 Success 触觉振动，弹出“奠基铭文（Foundation Note）”与拍立得生成器。

## 6. 系统底层架构与数据同步方案

### 6.1 平台感知抽象层 (`usePlatform`)
在 `src/platform/` 下建立统一的多端能力接口：

```ts
export type PlatformType = 'ios' | 'android' | 'desktop' | 'web'

export interface PlatformCapabilities {
  platform: PlatformType
  isMobile: boolean
  isDesktop: boolean
  safeArea: { top: number; bottom: number; left: number; right: number }
  haptics: {
    light(): void
    medium(): void
    heavy(): void
    success(): void
  }
  shareImage(blob: Blob, filename: string): Promise<void>
}
```

* **触觉反馈实现**：
  * 在移动端优先调用 Tauri Haptics 插件或原生振动 API（`navigator.vibrate` 作为保底回退）。
  * 桌面端自动降级为无操作（No-op），无需到处写条件分支。

### 6.2 本地存储与 WebDAV 双向同步方案

```
+-------------------------------------------------------------+
|                      BlockHabit 状态机                      |
|                  (Zustand: appStore.ts)                     |
+-------------------------------------------------------------+
                              |
                     [自动防抖订阅 500ms]
                              v
+-------------------------------------------------------------+
|                 本地持久化 (Local-First)                     |
|           Tauri 沙盒文件: appData/blockhabit-state.json      |
+-------------------------------------------------------------+
                              |
                     [WebDAV 同步引擎]
         (启动时自动拉取 + 变更后 5s 防抖推送 + 手动同步)
                              v
+-------------------------------------------------------------+
|                     WebDAV 云端服务器                       |
|           远程路径: /BlockHabit/blockhabit-state.json       |
+-------------------------------------------------------------+
```

1. **同步触发策略**：
   - **冷启动 / 前台激活（Resume）**：自动执行静默拉取（Pull）。若云端更新且有新打卡，则执行启发式合并。
   - **数据变更（打卡/修改习惯/摆放积木）**：本地立刻无等待落盘（0ms 延迟），5 秒防抖（Debounce）静默向 WebDAV 推送。
   - **网络离线**：本地正常打卡，标记待同步版本号；网络恢复后自动补传。
2. **CRDT 启发式冲突合并策略（Conflict Resolution）**：
   - **打卡记录集合 (`checkIns`)**：采用**并集去重（Union Merge by id / habitId+date）**。即使在不同设备离线打卡，合并时也绝不丢失任何一次记录。
   - **习惯列表 (`habits`)**：以单项 `updatedAt` 时间戳为准，保留最新字段变更；归档状态以最终归档为准。
   - **已建建筑与积木 (`builds`, `showcasePlacements`)**：积木按 `blueprintId + index` 去重合并；沙盘摆放位置以最新保存时间戳覆盖。
   - **补签砖石与全局计数**：合并双方消耗差值，确保计数守恒。

## 7. 错误处理与离线韧性

1. **网络超时与鉴权失效**：
   - WebDAV 同步失败时，右上角同步状态小标显示微弱灰色警告图标，点击展开错误原因（如“密码错误”或“网络超时”），严禁打断用户正常的打卡与建造体验。
2. **极端数据损坏防御**：
   - 每次从 WebDAV 拉取或写入本地前，对 JSON 结构进行严格的 `isValidState` 校验。
   - 本地写入前自动保留前一个有效版本的滚动备份（`blockhabit-state.backup.json`）。
3. **软键盘与页面抖动防御**：
   - 移动端输入习惯名称或备注时，页面外层使用 `height: 100dvh`（Dynamic Viewport Units），配合 `overflow: hidden` 与局部滚动，彻底避免移动端经典的视口被挤压破损问题。

## 8. 测试与质量验证策略

1. **自动化单元测试（Vitest）**：
   - 验证 WebDAV 冲突合并算法（CRDT 并集、并发打卡合并）。
   - 验证触控手势数学计算（双指扭动角度计算、Pinch 缩放边界钳制）。
   - 验证移动端 Safe Area 注入与平台判定逻辑。
