# BlockHabit 积木立体渲染设计规格（方案 A：Canvas 2D 渲染增强）

- 日期：2026-08-23
- 范围：`src/render/iso.ts`、`src/render/BuildScene.tsx`
- 目标：解决积木扁平铺贴、缺乏体积感、大圆角面间露底、块间粘连、凸点平面化等问题，实现接近真实乐高的等距积木观感。

## 1. 屏幕参数表

| 参数 | 值 | 说明 |
| --- | --- | --- |
| tileW | 48 | 顶面菱形宽（不变，蓝图坐标系与取景逻辑不动） |
| tileH | 24 | 顶面菱形高（不变） |
| blockH | 22 | 块身高度 ≈ 0.8 × 块宽的投影换算（原 24 → 22） |
| STUD_H | 5 | 顶部凸点圆柱层另加高度 |
| 整体比例 | 22 + 5 | 视觉接近真实乐高含凸点比例 |
| 面内缩量 | 0.6px（tileW×0.0125，下限 0.4） | 各面多边形沿边法线向内偏移 |
| 圆角半径 | min(2, tileW×0.045) ≤ 2px | 原大圆角收敛，三面共享精确边 |
| 剪影描边 | 1.25px，墨色 55% | 整块外轮廓 |
| 交界线 | 1px，墨色 35% | 顶/左/右三面交界（L→F→R 与 F→B） |
| 缝隙底色 | 墨色 12% | 剪影底衬，面收缩后缝隙透出 |
| 凸点半径 | rx = tileW×0.25 = 12，ry = rx×(tileH/tileW) = 6 | 直径 ≈ 0.5×tileW 的等距椭圆 |
| AO 压痕 | 墨色 15%，沿被压顶面边缘窄带（5px 描边取内半） | (x,y,z+1) 被占用时绘制 |
| 落地阴影 | z=0 块底边椭圆，墨色 22%，下偏 1px，ry=2.4 | 地面接触阴影 |

## 2. 比例

- `DEFAULT_ISO_CONFIG = { tileW: 48, tileH: 24, blockH: 22 }`，`STUD_H = 5`。
- 蓝图坐标系、`worldToScreen` 映射公式、Painter 排序与取景逻辑的坐标系均不变；仅块身高度常量由 24 调整为 22，取景上边界额外计入 STUD_H 余量。

## 3. 三面光照（光源左上）

三色均从 `theme.css` 现有 CSS 变量程序化派生（HSL 亮度乘法调整，钳制在 [0,1]），纸白/墨黑双主题自动生效，不按主题硬编码色值：

| 面 | 渐变方向 | 亮度（相对该面基色） | 派生系数 |
| --- | --- | --- | --- |
| 顶面（最亮） | 后缘 → 前缘 | 100% → 92% | base ×1.0 → ×0.92 |
| 左面（中等） | 上 → 下 | 70% → 60% | base ×1.0 → ×(60/70) |
| 右面（最暗） | 上 → 下 | 40% → 30% | base ×1.0 → ×(30/40) |

说明：每个面的 CSS 变量色定义为该面最亮缘（100% 锚点），暗缘按规格的百分比比例收缩，保证两套主题下相对明暗关系一致。每面用 `createLinearGradient` 沿渐变方向插值。

## 4. 轮廓与缝隙（解决块间粘连）

- 每个面多边形沿各边法线向内偏移约 0.6px（`insetPoly`），绘制顺序：
  1. 剪影底衬（未收缩六边形）填充墨色 12% —— 缝隙处透出的底色；
  2. 三面收缩多边形依次填充渐变（左 → 右 → 顶）；
  3. 面交界线 1px 墨色 35%；
  4. 整块剪影描边 1.25px 墨色 55%。
- 圆角从原 `max(3, tileW×0.1)` 大圆角收敛到 ≤2px，且三面共用同一套顶点与圆角半径，共享精确边，消除面间露底；上层块剪影可完全覆盖下层顶面菱形。

## 5. 圆柱凸点（每块顶面中央 1 个）

绘制顺序（`drawStud`）：

1. 底部接触阴影椭圆：墨色 18%，中心下偏 1.5px，半径 ×1.12；
2. 侧裙：圆柱侧面，亮度 = 左面亮度（×1.0），1px 墨色 35% 描边；
3. 顶面椭圆：比块顶最亮缘再亮 +8%（亮度乘法钳制 ≤100%），1px 描边；
4. 顶面左上高光弧：白色 60%，1.2px，取顶面椭圆 0.68 倍半径的左上弧段。

尺寸：rx = tileW×0.25（直径 ≈ 0.5×tileW），ry 按 tileH/tileW 等距压缩，高 STUD_H = 5。顶上有块（`(x,y,z+1)` 被占用）时省略凸点（`noStuds`）。

## 6. 堆叠遮挡与阴影

- Painter 排序保持现有 `(x+y 升序) → (z 升序)`，不改顺序逻辑。
- 接触阴影 AO：`(x,y,z+1)` 被占用时，在下层块顶面内（裁剪到顶面）沿边缘描 5px 宽墨色 15% 窄带；上层块覆盖后仅露边缘一线，形成“坐实”压痕。因排序保证同列下层先画、上层后画，AO 天然先于上层块绘制。
- 落地阴影：z=0 的块在剪影前先画一条椭圆地面接触阴影（≈2px 高）。
- 已放置块坐标集合 `placedSet` 判定 `hasAbove`，同时驱动 `noStuds` 与 `ao`（修正了旧实现中“下方有块即隐藏凸点”的语义错误）。

## 7. 风格纪律

- 全程黑白灰阶；琥珀点缀色（`--accent`）仅用于：连击奖励块顶面描边、window 类型窗装饰。不得扩大使用。
- window 装饰（左面，点缀色）与 gate 装饰（右面，墨色 55%，主题感知）保留并适配新面绘制，装饰圆角一并收敛到 1.5px。
- 虚影（ghost）模式保留：简化为剪影单色填充，供预览等场景使用。

## 8. 不改动的范围

- `src/logic/blueprints/`（generators、index、测试）不改；
- 存储层、store、页面组件不改（`BuildScene` 为渲染组件，属本次改动范围）；
- `depth(x+y+z)` 导出仅为测试保留，实际排序使用 BuildScene 内比较器。
