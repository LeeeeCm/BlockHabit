# BlockHabit — 极简黑白积木打卡 App 实施计划

## 产品定义

**BlockHabit**：桌面端习惯打卡应用。极简黑白风格 + 少量点缀色。每次打卡成功掉落一块 **2.5D 等距积木**，积木按蓝图逐渐拼成**城堡、工厂**等建筑，用"亲手搭建"的成就感驱动坚持。

## 已确认决策

| 决策项 | 结论 |
|---|---|
| 项目名 | BlockHabit（仓库 `blockhabit`） |
| 平台 | Windows 桌面应用，**Tauri 全程**（VS 2022 已有，需补装 Rust） |
| 技术栈 | Tauri 2 + Vite + React + TypeScript |
| 数据 | 本地优先（storage adapter 抽象：先 localStorage，Tauri fs JSON 持久化） |
| 积木视觉 | 2.5D 等距积木，Canvas 2D 手写投影（顶面亮灰/两面深浅灰，点缀色高亮） |

## 视觉设计

- **色板**：`#0A0A0A` 近黑 / `#FAFAFA` 纸白 / 灰阶层次；**点缀色 1 个**（琥珀 `#F5B301` 一类）只用于"已完成、今日新积木、连击奖励"三类高亮
- **积木着色**：等距立方体三面灰阶差；特殊积木（旗帜、窗户、大门）用点缀色，拼上时有落块动画
- **布局**：极简三栏导航——**今日 / 建造 / 统计**（+ 设置弹窗）；Inter/系统字体
- **Logo**：用 `ip-as-logo-skill` 方法论（4~7 个大形状剪影、≤3 色、可爱吉祥物——一个小方块角色），以 SVG 手绘落地（配合本地 `svg-icon-maker`）

## 核心功能（MVP）

1. **习惯管理**：增删改；名称、频率（每天 / 每周 N 次）
2. **今日打卡**：一键完成 + 确认动效
3. **积木奖励**：打卡成功 → 积木掉落动画落到蓝图下一个空位；连续打卡触发特殊积木
4. **建造视图**：等距场景，缩放/平移，进度（X/Y 块）；拼完触发"落成仪式"并可开启新蓝图
5. **蓝图主题**：城堡（首发完整）、工厂（第二个）
6. **统计**：连续天数、历史日历热图
7. **设置**：黑白主题反转、数据导出/导入 JSON

## 执行步骤

1. **装 skill**：`npx skills@latest add s1dashu/ip-as-logo-skill`（3.6k★ 已验证；其图像生成环节无环境支持，采用其设计方法论 + SVG 落地）
2. **写设计与计划文档**：按 brainstorming 流程输出 `docs/superpowers/specs/2026-08-22-blockhabit-design.md`，再用 `writing-plans` 拆实施计划；`git init` 并提交
3. **环境搭建**：安装 rustup（VS 2022/MSVC 已就绪，若缺 Windows SDK 再补）→ 脚手架 Tauri 2 + Vite + React + TS → 跑通空白窗口
4. **M1 核心闭环**：习惯 CRUD + 打卡逻辑（含单测 vitest）+ 单块积木掉落动画
5. **M2 建造视图**：等距渲染引擎、蓝图数据结构、城堡蓝图、进度与落成仪式
6. **M3 完整体验**：统计热图、工厂蓝图、连击特殊积木、导入导出、主题反转
7. **M4 品牌与打包**：SVG 吉祥物 logo + 应用图标 + `tauri build` 出安装包

## 风险与回退

- Rust 安装受阻 → 回退 Electron 封装（代码不变）
- 等距 Canvas 性能 → 只渲染视口内积木（规模小，预计无碍）

## 验收方式

- vitest 覆盖打卡规则、连击、蓝图进度等纯逻辑
- `browser-use`/`webapp-testing` 对浏览器版做 UI 验收，最终在 Tauri 窗口人工确认
