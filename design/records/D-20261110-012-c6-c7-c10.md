## 背景与问题

三处以「键盘 / 读屏用户不可用」为核心的缺陷（`D-20261110-004` 的 U10 / U9 / U13）：

1. **C6**：`useDialogA11y` 打开时无条件 `panel.focus()`，而 React 的 `autoFocus` 已在 commit 阶段把焦点放进名称输入框——于是被抢回面板容器。实测 Ctrl+N 新建习惯后，光标停在遮罩层而不是「习惯名称」，用户必须再点一次输入框。
2. **C7**：10 个 `role="dialog"` 弹窗中只有 `BottomSheet` / `ReminderDialog` 有可访问名称；`HabitDialog` 虽有 aria 属性但名称没落在对话框元素上。读屏软件只会念「对话框」。
3. **C10**：原生控件未收口——音量滑杆用 `accentColor: var(--accent)`（琥珀，违背 A1「点缀色只属于奖励」），周频滑杆用 `--progress-green`（语义色跑到了控件上），统计页筛选下拉无标签。

## 设计决定

### C6 保留面板内已聚焦元素
```ts
const active = document.activeElement as HTMLElement | null
const activeInside = active instanceof Node && panel.contains(active)
prevFocusRef.current = active && !activeInside ? active : null   // 只记录面板外的焦点用于恢复
const initial = initialFocusRef?.current ?? (activeInside ? active : panel)
initial.focus?.()
```
父组件 effect 晚于子组件 effect 执行，因此 `autoFocus` 先落定、hook 后运行——只要检测到焦点已在面板内就不再抢。显式 `initialFocusRef` 依旧最高优先。

### C7 十个弹窗逐个补名称（优先 aria-labelledby，画布型用 aria-label）
| 弹窗 | 方式 |
| --- | --- |
| `HabitDialog` | `aria-labelledby="habit-dialog-title"` + `<h3 id>` |
| `SettingsDialog` | `aria-labelledby="settings-dialog-title"` + `<h3 id>` |
| `ConfirmDialog` | `aria-labelledby="confirm-dialog-title"` + `<h3 id>` |
| `GalleryDialog` | `aria-labelledby="gallery-dialog-title"` + `<h3 id>` |
| `BlockDropModal` | `aria-labelledby="drop-modal-title"` + 头部标题 span 加 id |
| `FoundationNoteDialog` | `aria-labelledby="foundation-dialog-title"` + 标题 span 加 id |
| `MonthlyPosterModal` | `aria-label={t.poster.modalTitle}`（画布型，无可见标题） |
| `PolaroidModal` | `aria-label={isBack ? modalTitleBack : modalTitle}`（正反面语义不同） |

### C10 原生控件收口
- 音量滑杆 `accentColor: var(--accent)` → **`var(--ink)`**；周频次数滑杆 `var(--progress-green)` → **`var(--ink)`**。理由：滑杆是界面骨架而非进度/奖励语义，A1 规定点缀色不用于骨架，且原生蓝/绿会破坏黑白纪律。
- 补 `aria-label`：音量 `t.settings.volumeLabel`、周频 `t.habitDialog.timesPerWeek(n)`、统计筛选新增 `t.stats.filterByHabit`（zh/en/types 三处同步）。

## 取舍与被否方案

1. **否决「给每个弹窗新加一条 i18n 标题字符串」**：能复用既有可见标题就用 `aria-labelledby` 指向它——零新增文案、且读屏读到的是用户真正看到的那句话。
2. **否决「把滑杆换成自绘积木滑杆」**：那要新增一套控件与视觉语言；本轮只把原生控件的颜色收回到令牌（`--ink`），控件形态保持原生（可访问性最好）。
3. **否决「C9 的 HabitDialog 关闭前草稿确认」并入本轮**：会改动新建/编辑流程的状态机与现有测试，单独一轮做更安全。
