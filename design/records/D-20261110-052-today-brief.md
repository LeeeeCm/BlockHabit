## 背景与问题

今日页当前的结构是「日期 + 蓝图进度 chip + 习惯分组」，信息完整但没有回答用户打开应用后 3 秒内最关心的三个问题：今天还剩几件、做了会得到什么、从哪里开始。用户必须自己扫一遍卡片才能拼出进度，也没有任何「下一块积木何时落下」的预告——产品最强的资产（等距积木与建筑）在今日页只以一个百分比 chip 出现。

2026-11-10 的三份审计（D-003 / D-004 / D-005）指出了首次引导与长期使用的缺口，但没有覆盖「每天再打开时的动机」：引导解决第一次，简报解决每一次。

## 设计决定

在今日页标题行之下、习惯分组之上增加一条今日简报（TodayBrief），只在存在在册习惯且今天尚未全部完成时出现：

1. 问候语按本地时间切换（早上好 / 中午好 / 下午好 / 晚上好 / 夜深了），不使用感叹号与说教句式（遵循 VOICE.md）。
2. 一行事实：今天 N 件，一件一件来；或已完成 d/N，还有 p 件没落块——数字只来自 habitMetOnDay（A6 数据诚实）。
3. 一行期待：《蓝图名》还差 R 块落成；当前蓝图已满时改为下一座《蓝图名》已就绪。
4. 一个动作：主 CTA「开始第一个」直接定位到第一件未完成的习惯卡片（复用提醒跳转的滚动 + 脉冲高亮机制），不再让用户自己找。

外观只用现有令牌：--surface / --line / --r-md / --fs-subhead / --fs-small，不新增颜色、不新增阴影、不新增第三枚圆角档位。高度控制在 ~76px（两行 + 右侧胶囊按钮），窄窗口自动换行；全部完成时不渲染（全勤卡接管庆祝与领取）。

## 取舍与被否方案

- 否掉大仪表盘/进度环：违背 A4 留白与「极简在默认状态实现」；今日页是每天看 10 秒的页面，不是周报。
- 否掉每日一言/鸡汤：VOICE.md 禁止说教；简报只陈述事实与下一步。
- 否掉可关闭：简报是内容而非提示，关闭后今日页又回到「只有清单」；若窗口高度紧张，可后续做紧凑变体（记录待定）。
- 否掉在简报里放积木小图：等距缩略图需要 canvas 与 DPR 处理，首屏成本与视觉噪音都不划算；「还差几块」用文字已经足够。
- 否掉自动聚焦第一件：进入页面就抢滚动会打断看全貌，必须由用户点击 CTA。

## 验收标准

1. src/logic/todayBrief.test.ts：五个时段边界、空习惯、部分完成、全部完成、蓝图剩余块计算、下一座蓝图名。
