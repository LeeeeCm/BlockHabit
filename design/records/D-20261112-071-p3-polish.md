## 背景与问题

第十轮独立 verifier 留下 6 项 P3；用户确认「开始做」后，本轮处理其中不影响架构的两项可见/可用性问题，并把第三项（装饰会话态与 store 校验口径）如实写清：

1. 移动端（实验态）新增控件触控高度不足：装饰模式开关约 28.6px、设置页「检查更新」约 29px，低于 44px 触控目标（旋转按钮已 44×44）。
2. 图鉴「可开始建造但未开始」卡片显示「开始建造 · 94 / 94 块」，容量被读成进度，易误解。
3. 装饰模式的旋转是会话态，但 `updateShowcasePlacement` 的落位二次校验仍按基础 footprint（旋转态下极端拖拽可能被 store 拒绝回弹，无数据损坏）。

## 设计决定

- 新增工具类 `.touch-target-mobile`：仅在 `@media (max-width: 640px)` 下给 `min-height/min-width: 44px`；应用到装饰模式开关与「检查更新」按钮。桌面尺寸零变化；不新增颜色/圆角/阴影。
- 图鉴未开始卡片改为「开始建造 · 共 N 块」：新增 `gallery.totalBlocks(total)`（zh「共 N 块」/ en「N blocks」），不再显示 total/total 比例；进行中/已完成卡片保持进度口径。
- 装饰会话态：本轮**不改** store 接口（避免为会话态扩大持久层 API）；在 D-068 已知限制与发布报告如实保留说明；如未来需要彻底一致，另立记录评估把 rotations 传入 store 校验。

## 取舍与被否方案

- 否掉全局把所有按钮抬到 44px：桌面密度会明显变松，且移动端为实验态；只对两个新控件用媒体查询。
- 否掉图鉴全局显示「N 块」：已完成/进行中卡片需要进度；只改未开始态。
- 否掉为会话态旋转扩展 store 持久字段：违反 D-068「不新增持久化字段」与最小改动原则。

## 影响面

仅移动端两个按钮的触控高度、图鉴未开始卡片文案与 i18n；不改变数据、存档、同步、渲染与桌面布局。

## 验收标准

1. 390×844 移动端下装饰开关与检查更新按钮命中区域 ≥44×44；桌面（>640px）尺寸不变。
2. 图鉴未开始卡片显示「开始建造 · 共 N 块」；进行中仍显示 placed/total；已完成仍显示完成进度。
3. zh/en 文案齐全；四主题无新颜色；tsc/test/design:check/format:check 通过。
4. D-068 已知限制与发布报告继续如实记录 store 校验口径。
