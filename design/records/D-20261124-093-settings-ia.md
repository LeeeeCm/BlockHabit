## 背景与问题

设置原来有 8 个分组（界面偏好 / 声音 / 实验室 / 系统集成 / 数据安全 / 备份 / WebDAV / 关于），分类过细；「界面偏好」不是可折叠组，无法收起；桌宠没有独立设置入口。

## 设计决定

- 合并为 **4 组**，全部可折叠：
  1. **通用**（原界面偏好 + 声音 + 系统集成；默认展开）
  2. **数据与同步**（导出/导入、习惯导入、诊断包、备份、WebDAV；默认折叠）
  3. **关于**（内容路线 / 版本；默认折叠）
  4. **实验室**（光照、风化、生态、透视、音色、移动端陀螺仪、页面提示；默认折叠）
- 声音与系统作为「通用」组内的子段（细分隔线 + 小标题），不再各自成组。
- 诊断包从实验室移到数据与同步。
- 桌宠分组随桌宠重建（D-091）暂不进入本提交；设置结构预留后续插入位置。

## 取舍与被否方案

- 否掉「保留 8 组只把界面偏好改成可折叠」：用户明确嫌分类太细。
- 否掉「把 WebDAV 也塞进通用」：同步是数据操作，与通用偏好无关。
- 否掉「桌宠设置做成独立弹窗」：设置已有分组容器，复用可减少一层表面。

## 影响面

- 设置面板结构与分组标题；`groupPreferences` 文案改为「通用」、`groupData` 改为「数据与同步」。
- 无新增持久化字段（桌宠字段见 D-091）；无新颜色/圆角/字号。

## 验收标准

1. 设置只有 5 个分组，且每组标题可点击折叠/展开；通用组可收起。
2. 声音与系统在通用组内以子段出现；诊断包在数据与同步组内。
3. 右键桌宠打开设置时，桌宠分组位于视口顶部。
4. `tsc`、`vitest`、`format:check` 通过。
