## 背景与问题

产品的关键交互大多不可见：建造页的滚轮缩放 / 拖拽平移、展台页的拖拽摆放与「点建筑看落成相纸」、统计页热图灰阶的含义与点击行为、以及 1–4 数字键切页 / Ctrl+N 新建习惯。现有文案只在展台顶栏有一行静态提示，Build 页仅在 0 块时给地基说明；这些用法只能靠用户误打误撞。

「提示」不是再加一段说明文字，而是在正确时机、正确位置只出现一次，并能被重看。

## 设计决定

1. 新增通用组件 GuideTip：一张左下/页内的轻提示卡（图标 + 标题 + 一行说明 + 「知道了」按钮），使用 --surface/--line/--r-md/--fs-small 令牌，不遮弹窗、不抢焦点、不自动消失；role=note，按钮可键盘触发，Esc 可关闭。
2. 三处首次提示（每处仅在满足条件时出现一次）：
   - 建造页：已放置 ≥1 块时，左下角「这是你的工地 / 滚轮缩放、拖拽平移；落下的积木会按蓝图逐块咬合。」
   - 展台页：已有建筑时，「展台沙盘 / 拖动建筑换位置，点一下它会打开落成纪念相纸。」
   - 统计页：有习惯时，「这是你的时间形状 / 灰阶越深，那天完成得越多；点格子可以看那一天。」
3. 已读状态存 localStorage（blockhabit.guideTips.v1，字符串数组），不进存档 schema，不参与同步；设置页「实验室」组增加「重看页面提示」按钮，点击清空并 toast 确认。
4. 顶栏四个 tab 按钮补 title（含快捷键 1–4），提升桌面端可发现性；数字键切页逻辑已存在（App.tsx），仅补提示。

## 取舍与被否方案

- 否掉锚定式气泡（coach mark 指到具体控件）：需要测量目标元素位置、处理窗口缩放与滚动，脆弱且易遮挡；左下角轻提示卡更稳，也符合现有「提醒横幅 / 空态提示」的视觉语法。
- 否掉全屏遮罩引导：与 A5「不打断」及每日 10 秒的使用节奏冲突。
- 否掉每次进入都提示：那是打扰；「一次 + 可重看」是最小可发现性成本。
- 否掉把快捷键说明塞进设置页长列表：设置已经 2.7 屏；快捷键只在 tab 的 title 里出现，不新增常驻界面。

## 影响面

## 验收标准

1. 清空 localStorage 后：分别首次进入三页各出现一次提示；点「知道了」后不再出现；刷新仍不出现。
2. 设置页「重看页面提示」后，三页提示重新出现一次。
3. 提示卡不拦截页面交互（除自身按钮）；Tab 可聚焦「知道了」；Esc 关闭；prefers-reduced-motion 下无位移/缩放动画。
4. 四主题截图：无新增色相、无新阴影；窄窗口（≤ 820px）不与底部 tab 栏重叠。
5. tsc / npm test / npm run design:check 通过。
