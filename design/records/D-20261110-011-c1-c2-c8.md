## 背景与问题

审计（`D-20261110-004`）实测发现三处「长期使用」缺口，且都属于**默认观感不该改变、但不做就是硬伤**的类型：

1. **C1**：全仓 `prefers-reduced-motion` **0 处**。系统开启「减少动态效果」后，弹窗照常 pop-in、canvas 落块动画照播 1350ms。这与 `design/README.md` A5「所有动画必须尊重 prefers-reduced-motion」直接冲突，也会让前庭功能敏感用户难受。
2. **C2**：全仓 `:focus-visible` **0 处**。黑底控件（激活 tab、主按钮）上的 UA 默认 outline 实测对比度 1.06:1，键盘用户**看不见焦点在哪**，等于键盘全流程不可用。
3. **C8**：UI 在 `hydrated` 之前就渲染，而主题来自异步读档（Tauri 走文件）→ 暗色/燕麦/雾灰主题每次冷启动都先闪一帧纸白；浏览器端也一样。

## 设计决定

### C1 动效令牌 + 减少动态降级
- `theme.css` 的 `:root` 新增**动效令牌**：`--dur-xs/sm/md/lg`（120/200/320/500ms）与 `--ease-standard` / `--ease-bounce`。令牌先于代码，后续 D3 的时长收口以它为目标。
- 新增 `@media (prefers-reduced-motion: reduce)`：① 四个时长令牌归零；② 全局兜底 `animation-duration/transition-duration: 0.01ms !important`、`animation-iteration-count: 1`、`scroll-behavior: auto`。
- **canvas 侧**：`platform/dom.ts` 新增 `prefersReducedMotion()`（matchMedia 缺失/抛错时安全返回 false）；`BuildScene` 的动画启动 effect 命中 reduce 时**不建动画/级联对象**，积木直接落位并立即回调 `onAnimated`（否则落块弹窗会等一个永远不来的动画结束事件）。

### C2 键盘焦点环
```css
:focus:not(:focus-visible) { outline: none; }
:focus-visible { outline: 2px solid var(--ink); outline-offset: 2px; }
```
- 只用 `--ink`，**不新增任何色相**，与 A4「留白与 1px/2px 细线」的语言一致；`outline-offset: 2px` 让环落在元素外侧的页面底色上，因此在黑底胶囊按钮上也可见（实测已确认）。
- 不使用 `box-shadow` 做双环：会覆盖组件既有的软阴影，反而破坏 A4。

### C8 首帧外观缓存
- 新增 `platform/appearance.ts`：`cacheAppearance(theme, lang)` 与 `applyCachedAppearance()`，键 `blockhabit-theme` / `blockhabit-lang`（与存档无关，纯「绘制提示」）。
- `main.tsx` 在 React 挂载前调用 `applyCachedAppearance()`，先把 `data-theme` / `lang` 摆正；`App.tsx` 在主题/语言 effect 中回写缓存。
- 真值仍以存档为准（effect 会立刻覆盖），缓存非法值被忽略，`localStorage` 抛错静默降级。**未**新增闪烁、未延迟渲染、未引入 loading 态。

## 取舍与被否方案

1. **否决「按组件逐个改写 transition 为令牌」（D3 全量收口）**：17 档时长/7 种缓动的替换会产生大面积无关 diff，本轮用「令牌 + 全局兜底」先达标（系统开关生效），收口留给 D3。
2. **否决「用 `hydrated` 闸住整页渲染」消除空态闪现**：会与现有 `App.test.tsx`（mock 掉 initPersistence，永不 hydrated）冲突，且引入白屏等待。主题闪变用缓存解决，**空态闪现**仍留在待办（需要「视觉隐藏但不卸载」的方案）。
3. **否决「焦点环用 --accent 琥珀」**：A1 规定点缀色只用于奖励语义；焦点环是界面骨架，必须用无彩度的 `--ink`。
4. **否决「焦点环用 box-shadow 双环」**：会覆盖卡片/胶囊既有的软阴影。

## 影响面

- 代码：`theme.css`（新增约 45 行，无既有声明被改）、`platform/dom.ts`、`platform/appearance.ts`（新）、`render/BuildScene.tsx`（动画启动分支）、`main.tsx`、`App.tsx`、tsconfig 排除项、3 个新测试。
- 用户可见：① 键盘用户能看到焦点；② 系统开启「减少动态」后动画瞬时完成；③ 暗色/燕麦/雾灰主题启动不再闪白。**默认状态下的布局、颜色、字号、动效参数一律未变**。
- 风险：全局 `*` 兜底只在 reduce 媒体下生效，普通用户无感。

### 自动化（已通过）
- `src/themeMotion.test.ts`（4 例）：动效令牌齐全、reduce 媒体块存在且令牌归零、焦点环使用 `var(--ink)` 且无硬编码颜色、四主题块未被误删。

- 全量：`npx tsc --noEmit` 0 错误；`npm test` 全绿。

### 浏览器实测（2026-11-10 02:2x，`npm run dev` + agent-browser）
- 连按 Tab：`绿意盆栽` 胶囊出现 2px 黑色描边（截图 `.tmp-verify/focus-ring.png`），此前该元素无任何焦点指示。
- `getComputedStyle(document.documentElement)`：`--dur-md` = `320ms`、`--ease-standard` = `cubic-bezier(0.2, 0, 0, 1)`（令牌在浏览器里真实生效）。
- 聚焦元素计算样式：`outline: 2px solid rgb(10, 10, 10)` = `var(--ink)`，与令牌一致。
