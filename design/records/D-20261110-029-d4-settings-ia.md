## 背景与问题

审计 D4（P2）：设置面板是「平铺一切」的：**19 个控件、约 1956px 内容塞进 543px 视口 = 3.6 屏**，六组全部展开、没有层级。用户想改主题要滚动，想找同步要滚动，想找「实验性开关」也要滚动——而且实验性功能与日常设置混在一起。

## 设计决定

### 1. 分组容器化：`<Group collapsible defaultOpen>`
新增内部组件 `Group`（在 `SettingsDialog.tsx` 内，不新增文件）：
- 复用既有 `.apple-group` / `.apple-group-title` 视觉语言，**零新增颜色、零新增圆角/阴影**；
- `collapsible` 时标题行右侧出现 `›`（复用今日页的同一字符），展开时旋转 90°，过渡用上一轮的 `--dur-xs` / `--ease-default` 令牌；
- 可访问性：`role="button"` + `tabIndex=0` + `aria-expanded` + Enter/Space 切换；
- 展开态只存在组件 `useState`，**不写设置、不影响持久化**。

### 2. 六组重排为「首屏必备 + 折叠进阶」
| 分组 | 默认 | 内容 |
| --- | --- | --- |
| 界面偏好 | **展开** | 语言、主题、到点提醒 |
| 声音 | 折叠 | 音效开关 + 音量（从「界面偏好」拆出） |
| 实验室 | 折叠 | 环境光、温柔衰减、透视考古默认、陀螺仪、迷你悬浮件（原「感官与氛围体验」更名） |
| 数据安全 | 折叠 | 导出 / 导入 |
| 备份与恢复 | 折叠 | 备份列表 / 恢复 / 打开目录（仅桌面端） |
| WebDAV 数据同步 | 展开 | 同步配置与手动同步 |

「声音」之所以单拆：它是一组**感官设置**，与「语言/主题」这类外观设置不是一类；拆出后「界面偏好」只剩 3 个控件，首屏刚好容纳。

### 3. 顺带处理一个未使用的键
原 `settings.ambienceTitle`（「感官与氛围体验」）随改组更名为 `labTitle`（「实验室」），旧键删除（在 types / zh / en 三处同步）。

## 取舍与被否方案

1. **否决「改用原生 `<details>`」**：`<details>` 的默认 marker 样式与 `.apple-group-title` 冲突，且无法复用现有标题排版；自建 20 行组件更可控。
2. **否决「把展开状态持久化」**：用户下次打开设置时，看到与上次不同的折叠状态会困惑；默认状态应当稳定可预期。
3. **否决「用抽屉/二级页面承载进阶设置」**：那要新增导航层级与返回逻辑，超出「信息架构收口」的范围；折叠分组已经解决 3.6 屏问题。
4. **否决「把 WebDAV 也默认折叠」**：同步状态（上次同步时间/失败提示）需要一眼可见，折叠会让「同步坏了」变得不可发现。

## 影响面

- 代码：`SettingsDialog.tsx`（新增 Group 组件 + 6 组包裹 + 声音组拆分）、i18n 两种语言 +2 键 −1 键。
- 用户可见：设置面板**首次打开只需看一屏**；进阶项点标题展开。配色/控件/字号/圆角全部沿用既有令牌。

## 验收标准

### 结构验收（浏览器实测）
| 指标 | 改前（审计基线） | 改后（625px 窗口实测） |
| --- | --- | --- |
| 内容高度 / 视口 | 1956px / 543px = **3.6 屏** | 1164px / 427px = **2.73 屏（−24%）** |
| 首屏可见 | 语言、主题、音效、音量、提醒（5 项） | **语言、主题、提醒 + 折叠的「声音」标题** |
| 分组标题 | 6 个全部展开 | 4 个可折叠 + 2 个默认展开 |

折叠交互实测：点击「声音」→ `aria-expanded` 由 `false` 变 `true`、音量滑杆（`input[type=range]`）随之出现；「实验室」「数据安全」保持 `false`；「界面偏好」不带 `aria-expanded`（不可折叠）。
